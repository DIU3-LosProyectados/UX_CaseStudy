## Conclusiones

En esta tercera práctica hemos desarrollado el prototipo de alta fidelidad (Hi-Fi) del proyecto Goiko en formato landscape, estructurado mediante una retícula de 12 columnas que permite una organización flexible, equilibrada y escalable de los contenidos. A partir de los wireframes elaborados previamente, hemos redefinido la interfaz para lograr una experiencia visual clara, con jerarquías bien definidas y una disposición horizontal que favorece la legibilidad y el protagonismo del producto.

El proceso ha supuesto un reto adicional respecto a fases anteriores, especialmente por el uso de herramientas avanzadas en Figma, como la creación de componentes complejos y la aplicación de sistemas de diseño basados en grids. Además, hemos trabajado siguiendo una metodología de diseño atómico, desarrollando átomos, moléculas y organismos, lo que nos ha permitido construir una base coherente y reutilizable para toda la interfaz.

El prototipo final refleja una propuesta sólida y consistente, en la que se integran tanto la estructura en retícula como el enfoque sistemático del diseño. Más allá del resultado visual, este ejercicio ha sido clave para entender cómo organizar y escalar una interfaz digital, así como para trasladar una idea conceptual a una solución funcional preparada para su validación.
