## 3. Análisis por Principios (POUR)

### A. Perceptible
* **Hallazgo 1: Posibles problemas de contraste entre texto y fondo**
  * **Criterio WCAG incumplido:** 1.4.3 - Contraste mínimo.
  * **Impacto:** Los usuarios con baja visión pueden tener dificultades para distinguir determinados elementos visuales y textos.
  * **Recomendación:** Verificar todas las combinaciones de color mediante herramientas de contraste y asegurar una relación mínima de 4.5:1.

* **Hallazgo 2: Imágenes sin descripción alternativa verificable**
  * **Criterio WCAG incumplido:** 1.1.1 Contenido no textual.
  * **Impacto:** Los usuarios de lectores de pantalla podrían no comprender el contenido visual.
  * **Recomendación:** Añadir atributos `alt` descriptivos a las imágenes relevantes y marcar las decorativas con `alt=""`.

### B. Operable
* **Hallazgo 3: Navegación mediante teclado no completamente verificable**
  * **Criterio WCAG incumplido:** 2.1.1 - Teclado.
  * **Impacto:** Algunos usuarios podrían no poder acceder correctamente a elementos interactivos utilizando únicamente el teclado.
  * **Recomendación:** Comprobar que todos los enlaces, botones y componentes interactivos sean accesibles mediante Tab y Enter.

* **Hallazgo 4: Indicador de foco insuficiente o poco visible**
  * **Criterio WCAG incumplido:** 2.4.7 - Foco visible.
  * **Impacto:** Los usuarios pueden perder la referencia de navegación dentro de la página.
  * **Recomendación:** Aplicar estilos visuales claros para `:focus` y `:focus-visible`.

### C. Comprensible
* **Hallazgo 5: Tipografía decorativa con posible impacto en la legibilidad**
  * **Criterio WCAG relacionado:** 3.1 y 3.2 Comprensibilidad.
  * **Impacto:** Algunos usuarios con dificultades cognitivas o dislexia pueden requerir un mayor esfuerzo de lectura.
  * **Recomendación:** Mejorar tamaño, espaciado e interlineado de los textos.

* **Hallazgo 6: Estructura jerárquica de encabezados no verificable**
  * **Criterio WCAG incumplido:** 1.3.1 - Información y relaciones.
  * **Impacto:** Los lectores de pantalla podrían no interpretar correctamente la organización del contenido.
  * **Recomendación:** Utilizar encabezados semánticos (`h1`, `h2`, `h3`) siguiendo una jerarquía lógica.

### D. Robusto
* **Hallazgo 7: Etiquetas accesibles y roles ARIA no verificables**
  * **Criterio WCAG incumplido:** 4.1.2 Nombre, función y valor.
  * **Impacto:** Las tecnologías de asistencia pueden no identificar correctamente algunos elementos interactivos.
  * **Recomendación:** Revisar la implementación HTML y añadir atributos ARIA cuando sea necesario.

* **Hallazgo 8: Posible uso excesivo de contenedores genéricos**
  * **Criterio WCAG incumplido:** 1.3.1 y 4.1.2.
  * **Impacto:** Los lectores de pantalla pueden perder información estructural importante.
  * **Recomendación:** Utilizar etiquetas semánticas como `main`, `nav`, `header`, `section` y `footer`.
